## Design

The Orchestrator freezes one hashed acceptance bundle into each Backtest child. Producers execute it against clean synthetic/schema fixtures and preflight their terminal envelope; Gate reruns the identical bundle and independently classifies findings. Transition keys combine candidate, task, artifact lineage, defect ID, and correction ordinal. One new bounded implementation defect after Advanced may receive one correction and one re-Gate; repeats and material changes stop.

The configuration update is a compensated five-object transaction with exact before text/hash and verified readback. Replay is isolated from the live frontier and uses no project holdout bytes.
